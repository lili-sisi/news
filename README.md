### 简要介绍
知乎日报的仿写，实现了首页的轮播图，上拉加载更多，部分新闻点击进入详情页，点击查看评论等功能，
1.首页使用concatadapter，将轮播图和下面的新闻列表拼成一起，让轮播图可以随新闻列表的上滑而上滑。
2.上拉加载更多用ScrollListener监听屏幕滑动，当滑到倒数第二条的时候就开始加载更早的新闻，
3.详情页用viewpage2+wedview实现（虽然逻辑并没有写完）
4.实现了banner的无限轮播与手动滑动。把 getItemCount 返回 定为Int.MAX_VALUE，初始化时，把 ViewPager2 跳到 中间位置，真实位置 = 当前位置 % 数据数量，并设置了一个监听，当手指滑动的时候停止播放，手指松开的时候再开启播放，防止二者冲突
